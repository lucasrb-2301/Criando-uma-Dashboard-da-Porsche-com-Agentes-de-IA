# Criando-uma-Dashboard-da-Porsche-com-Agentes-de-IA

Sobre o projeto
Do registro de venda à decisão comercial
Este painel transforma a base de 100 vendas de Porsche (planilha Base-porshe.xlsx) em respostas diretas para a gestão da concessionária: onde está a receita, por qual canal de pagamento ela chega e quanto dela já virou entrega. Os três gráficos respondem a uma pergunta cada, e os filtros e indicadores de topo recalculam tudo em tempo real.

Como usar
Filtros: modelo, cidade, ano do modelo, pagamento e situação. Combine à vontade e use "Limpar filtros" para voltar.
Gráficos: passe o mouse para ver valores, vendas e ticket médio.
Tabela: o botão "Ver tabela" mostra os mesmos números em formato tabular.
Tratamento dos dados
Uso das colunas já padronizadas (cidade, modelo, pagamento e situação).
Linha de modelo derivada do nome (911, 718, Cayenne, Macan, Taycan, Panamera).
Situação agrupada em Entregue, Em andamento e Cancelada.
Datas de venda descartadas: 24 "INVALID" e várias no futuro.
Definições e tecnologia
Receita, vendas e ticket excluem canceladas; a Pergunta 3 as inclui (valor bruto).
Valores em dólares (US$), como na base.
Tecnologia: HTML, CSS e JavaScript puros em um único arquivo, sem bibliotecas; dados embutidos; tema claro/escuro automático.
